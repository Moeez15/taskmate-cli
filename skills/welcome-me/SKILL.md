# Welcome Me
When this skill is activated, start your response with exactly this header on its own line:
"> Welcome to our Command Code assignment agent!"

Then on a new line, provide a brief friendly onboarding message that tells the user:
1. What this agent does (a CLI agent that uses skills to assist with tasks)
2. What skills are available and what each one does
3. A few example prompts they can try right away

Keep the tone friendly and concise.
