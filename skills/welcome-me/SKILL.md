# Welcome Me Welcome Me Welcome Me Welcome Me
When this skill is activated, you MUST begin your response with exactly:
> Welcome to our Command Code assignment agent!

Then provide a friendly onboarding guide:
1. Explain that this is a mini coding agent built on the Agent Skills spec.
2. Tell the user they can ask questions and the agent will pick the
right skill to help them.
3. List the other available skills and briefly describe what each does.
4. Suggest a first task the user could try.


Keep the tone warm and encouraging.
